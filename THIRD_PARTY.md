# Third-party content

Some directories in this repository are vendored copies of open-source projects (not git submodules). A plain `git clone` includes everything; no `git submodule update` is required.

| Directory | Upstream | Details |
|-----------|----------|---------|

Each vendored directory contains a `SOURCE.md` with the pinned commit and upstream URL.
